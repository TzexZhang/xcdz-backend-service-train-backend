# WebSocket 按条件增量推送 + 数据模拟入库 实施计划（与此前查阅版本一致）

## 架构
模拟器（扮演第三方）INSERT → MySQL child_record 表 → PushTask 每秒按自增 id 水位轮询增量 → 按会话过滤（parentIds + collect_time ∈ [start, end]，含迟到补录数据）→ WebSocket 推送 DATA_ADD / WINDOW_CLOSED。写入方与推送方完全解耦（手动 SQL 插入也能被推送）。

## 表结构（sql/schema.sql，手动在 practise 库执行）
- parent_node（父节点，固定，String 雪花 id）+ child_record（子表即数据表，Long 自增 id 作水位，含 parent_id/metric_value/collect_time，联合索引 idx_parent_time）
- 附 4 条演示父节点数据

## WebSocket 契约（ws://localhost:9900/ws/data）
- 入：SUBSCRIBE（parentIds 可空=全部 + startTime/endTime 绝对时间段）、UNSUBSCRIBE、PING
- 出：SUBSCRIBED、INIT（≤500 条快照）、DATA_ADD、WINDOW_CLOSED（now>endTime 一次性通知，迟到数据仍推）、DATA_REMOVE（预留）、PONG、ERROR

## 新增文件（全部新建，零修改现有文件，零新增依赖）
sql/schema.sql；entity/ParentNode、ChildRecord；mapper 两个；service 接口+impl 两个（条件查询/水位增量查询）；vo/ParentNodeVO、ChildRecordVO；config/WebSocketConfig（/ws/data）、SchedulingConfig（@EnableScheduling）；websocket/WsMessage、DatasourcePushHandler、PushSessionManager（ConcurrentHashMap + 每会话 synchronized 发送）、DatasourcePushTask（全局水位 + 全局锁保证订阅/推送互斥，无重复无遗漏）；simulate/DataSimulator（@Scheduled 1s tick + 可调间隔默认 2s + 概率回拨 collect_time 模拟迟到数据）、SimulateController（start/stop/interval）；controller/ParentNodeController（/parentNode/list + /childRecord/query 对账）；static/ws-test.html 测试页。

## 验证
执行 schema.sql → 启动应用 → 开 ws-test.html 订阅 → 观察 INIT/每 2s 入库后 1s 内 DATA_ADD → 手动 INSERT 验证解耦 → endTime 到点收 WINDOW_CLOSED → REST 对账条数一致 → mvn compile 通过。
